# Columbia Gorge Web Works

Marketing/portfolio site for Columbia Gorge Web Works — a solo web developer business based in Hood River, OR, building and maintaining sites for wineries, breweries, and similar hospitality businesses in the Columbia Gorge.

See [PROJECT-BRIEF.md](./PROJECT-BRIEF.md) for the source of truth on content, sitemap, and pricing. See [CLAUDE.md](./CLAUDE.md) for project conventions.

## Stack

- [Astro](https://astro.build) + TypeScript
- Tailwind CSS

## Commands

| Command           | Action                                      |
| :----------------- | :------------------------------------------- |
| `npm install`       | Install dependencies                        |
| `npm run dev`       | Start local dev server at `localhost:4321`  |
| `npm run build`     | Build production site to `./dist/`          |
| `npm run preview`   | Preview the build locally before deploying  |
